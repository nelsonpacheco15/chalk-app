# Chalk: project roadmap

Goal: become a professional calisthenics athlete with a lean, 3D-shoulder physique and fixed posture, while logging everything with as few taps as possible.

## Done (v1)
- 6-day Push / Pull / Legs+Core plan with a Sunday mobility day. Exercises rotate weekly A → B → C.
- Mobility warm-up checklist before every session, including posture work for rounded shoulders.
- Logging prefills last session's numbers, starts a rest timer after each set and shows "add weight" hints.
- 11 skill ladders (front lever, planche, HSPU, press/OAHS, back lever, Hefesto, OAP, advanced muscle-ups, flag, V-sit/manna, dragon flag). The current step of up to 3 focus skills goes into sessions automatically.
- One-tap food log against 2,100 kcal / 140 g protein, with saved meals, copy yesterday and quick add.
- Progress tab: bodyweight trend, skill personal bests, streak, 7-day nutrition, backup/restore.
- Athlete guide covering training, posture, nutrition and recovery.

## Next
1. **Get it on the phone:** host it (GitHub Pages or Vercel) so it installs from the home screen and works offline.
2. **Deload week:** automatically every 4th week (volume −40%), following the guide.
3. **Monthly check-in:** posture photo reminder on the 1st, plus a bodyweight trend review.
4. **Combo builder:** chain mastered skills into freestyle/static routines for competition prep.
5. **Exercise swap:** long-press to swap an exercise when equipment is taken.

## Review every 4 weeks
- Can I level up any focus skill? Then swap in a new focus skill.
- Bodyweight trend: losing 0.3–0.5 kg/week? If faster, add 150 kcal.
- Posture photo compared with last month.
